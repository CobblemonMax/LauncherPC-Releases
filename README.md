# Cobblemon Max Launcher (PC) - Releases

Este repositório guarda só os instaladores do launcher para PC.
O launcher lê as releases daqui para se atualizar sozinho (electron-updater).

O código-fonte fica em um repositório privado. As releases são publicadas
automaticamente pelo GitHub Actions quando uma tag `v*` é enviada.

Não apague o arquivo `latest.yml` das releases: é ele que o launcher consulta.
