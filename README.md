## 🖥️ Sobre o LauncherPC

O **LauncherPC** é o launcher oficial do **CobblemonMax para computadores**, desenvolvido para oferecer uma experiência simples e integrada para acessar o servidor.

Este repositório é destinado exclusivamente à **publicação e distribuição das versões oficiais do launcher**.

Aqui você encontrará:

* Novas versões do LauncherPC
* Correções de bugs
* Melhorias de desempenho e estabilidade
* Atualizações de compatibilidade
* Instaladores oficiais para Windows, Linux e macOS

---

## 📦 Download

As versões oficiais estão disponíveis na seção **Releases** deste repositório.

Escolha o arquivo correspondente ao seu sistema operacional:

| Sistema | Plataforma | Distribuição |
| --- | --- | --- |
| 🪟 **Windows** | Windows 10 / 11 | Instalador oficial |
| 🐧 **Linux** | Distribuições compatíveis | Pacote para Linux |
| 🍎 **macOS** | macOS | Aplicativo para macOS |

> **Recomendação:** utilize sempre a versão mais recente disponível para garantir melhor compatibilidade, estabilidade e acesso às últimas correções e funcionalidades.

---

## 🔄 Atualizações automáticas

O **LauncherPC** possui suporte a atualizações automáticas.

Quando uma nova versão oficial é publicada, o launcher pode verificar a disponibilidade da atualização e utilizar os arquivos distribuídos através deste repositório.

Dessa forma, os jogadores podem manter o launcher atualizado sem precisar acompanhar manualmente cada nova versão publicada.

## 🔒 Segurança

Baixe o **LauncherPC** somente através das fontes oficiais do **CobblemonMax**.

Evite utilizar instaladores redistribuídos por terceiros, versões modificadas ou arquivos provenientes de fontes desconhecidas.

As versões publicadas neste repositório correspondem ao canal oficial de distribuição do launcher.
